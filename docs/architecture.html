Factory Inventory Management — System Architecture

Full-stack SPA with Vue 3 frontend, Python FastAPI backend, and in-memory mock data

Vue 3 + Vite FastAPI + Pydantic In-memory JSON i18n (en / ja) 7 Views · 9 Components · 3 Composables

System Architecture

Frontend  :3000
  • Vue 3 Composition API
  • Vue Router 4
  • Vite dev server
  • Axios HTTP client
  • Vanilla CSS (no framework)
State & Logic

  • useI18n — en/ja locale
  • useAuth — mock user/tasks

  • Dashboard — KPIs & charts

  • Orders — order management
  • Demand — forecasts
  • Spending — cost analysis
  • Reports — analytics
  • Backlog — unfulfilled orders
HTTP / JSON
axios GET

  • FastAPI (Python)
  • Pydantic v2 models
  • CORS (all origins)
  • Auto docs at /docs

4 Global Filters
Time Period → month param · supports monthly (2025-01) & quarterly (Q1-2025)
Warehouse → warehouse param · San Francisco, London, Tokyo
Category → category param · Circuit Boards, Sensors, Actuators, Controllers, Power Supplies
Order Status → status param · Delivered, Shipped, Processing, Backordered

API Endpoints

GET /api/inventory inventoryFilters: warehouse, category
GET /api/inventory/{item_id} inventorySingle item by ID
GET /api/orders ordersFilters: warehouse, category, status, month
GET /api/orders/{order_id} ordersSingle order by ID
GET /api/dashboard/summary dashboardAll filters — KPI summary
GET /api/demand demandNo filters — full forecast list
GET /api/backlog backlogNo filters — adds has_purchase_order flag
GET /api/spending/summary spendingTotal spend summary
GET /api/spending/monthly spendingMonthly breakdown
GET /api/spending/categories spendingCategory breakdown
GET /api/spending/transactions spendingRecent transaction log
GET /api/reports/quarterly reportsQuarterly stats (orders, revenue, fulfillment)
GET /api/reports/monthly-trends reportsMonthly order counts & revenue

KPI cards, order health donut, inventory by category, top products, backlog table. Promise.all() for 4 concurrent API calls.

Orders

Demand
